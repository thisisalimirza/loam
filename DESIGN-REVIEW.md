# Loam OS — design review (taste pass)

Separate from CRITIQUE.md (the bug and overlap critic). This file only covers simplification: what to merge, hide, demote, regroup or remove so the app feels like a set of Apple apps rather than a pile of features. Read-only; no code changed.

## 2026-10-28 design review

Method: production (https://thisisalimirza.com/os), signed in as Ali (real data, not test mode), around 4:50–5:00 PM EDT. 13 list routes + area, project, site-edit, site-new details + capture sheet + task panel at 390 / 1180 / 1512. Shots: `shots/design-review-2026-10-28/w<width>_<route>.png`. Sources: DESIGN-PRINCIPLES.md, VISION.md and the "Loam OS × Apple design plan" canvas (read from the store). Not reached: people/note/journal/draft detail pages (no rows exist), board card panel (selector missed; task panel is the same component), capture sheet at 390 (the bar didn't open on click), and `/os/journal/write` (skipped because opening it creates an entry).

Ranked by impact (biggest first). Items the critic already raised are only included where the fix here is broader.

1. **regroup — Navigation (all pages, all widths).** The desktop sidebar has 11 items plus an "Areas" section listing areas again. Areas shows up in three places: the Areas nav item, the sidebar Areas section, and Settings › Areas. The phone tab bar has a different set: Board is a tab, and More holds 8 rows, including Inbox (not on desktop) and "Areas & projects" (called "Areas" on desktop). *Why:* the two layouts disagree, and the same thing appears several times. *Change:* use VISION's spaces at every width: **Today · Tasks · Write · Projects**, then People, Weekly review and Settings in a quieter footer group. Remove the Board nav item and tab, since Tasks already has List | Board (`w1180_os_tasks.png`). Remove the sidebar "Areas" section. Rename "Areas" to "Projects" everywhere. Remove Inbox from More. Phone tabs: Today, Tasks, Write, Projects, More. Shots: `w1512_os.png`, `w390_os_more.png`, `w1180_os_areas.png`.
2. **merge — Capture (desktop 1180/1512).** There are two always-visible controls for the same ⌘K sheet: the sidebar "Search or capture ⌘K" field and the floating "Add a task, note, or person… ⌘K" bar. Both are on screen together, even with the sheet open (`w1512_capture_open.png`). The floating bar also shows on only some pages: Today, Areas, Journal, Review, Settings and Site edit have it; Tasks, Board, People, Notes and Drafts don't. It also shows on Site edit even though the latest commit hides it on writing pages, and its width doesn't match the content column (250–873px vs 250–989px at 1180). *Change:* at ≥820px keep only the sidebar field. Use the floating bar on phones only, and on the same pages every time.
3. **demote — Task detail panel (`w1180_tasks_panel.png`, `w390_tasks_panel.png`).** The panel shows 11 controls at once. Column, "3h in column" and "Waiting on" show up even when the task is opened from the List view. Checklist items use the browser's square checkbox next to the app's round ones. There's no Cancel/Done. *Change:* show Title, Due, Project, Notes and Checklist. Put Priority, Repeat, Tags and Waiting on under a "More details" disclosure. Show Column and time in column only when opened from Board. Use the round check for checklist items. Add Cancel/Done (principle 6).
4. **merge — Today (`w1512_os.png`, `w390_os.png`).** The page has a "1 due today" subtitle, a floating "Today's journal" widget (top right on desktop, half width on phone), and one project card that holds the countdown, progress bar, ⓘ icon, task row, "Today" label and "Pinned" chip. Today's task only exists inside the project card, so there is no Today list. *Change:* large title → one **Today list** (overdue + due today, like Reminders), with "Write today's journal" as a row in that list → a slim "Your projects" strip showing only name + "37 days left". Remove the subtitle, the ⓘ icon, the "Pinned" chip and the journal widget.
5. **merge — Area detail (`w1180_os_areas_detail.png`, `w390_os_areas_detail.png`).** IM Rotation appears twice: as a project row ("Dec 4") and as a separate "37 days IM Rotation" countdown card. "Finish 20 more UWorld questions" also appears twice: in Tasks and as the project row's subtitle. At 390 the countdown card is inset 16px narrower than the cards above it. *Change:* remove the countdown card and show "37 days" as the project row's trailing meta. Drop the next-task subtitle when the task list is on the same page. Hide the "No people linked…" instruction.
6. **remove — Board header differs by width (`w390_os_board.png` vs `w1180_os_board.png`).** At 390 the Board has the "All work" eyebrow, a subtitle with "Press ? for shortcuts", "Lanes", a "1 open · 0 in progress" stats row, and a segmented To do/Doing/Done control while the next column still peeks in. At 1180 the same control says "Group by area" and there's no eyebrow or stats. *Change:* use one header at every width: title only, then search · Filter · Group by area. Remove the stats row and the shortcut text, and hide "?" on touch. On phones the segmented control shows exactly one column with no peek.
7. **hide — Empty sections still get a header and a zero count.** Examples: People "Everyone 0" + "No one yet", Journal "Entries 0", Inbox "Unfiled 0", Review "Done this week · Nothing marked done yet", and Drafts with five empty columns all showing 0. Review also says "0 done · 0 journal days" and then "0 words in the journal this week". *Change:* at zero, show no header and no count. Use a one-line empty state with one button, plus suggestions where they exist ("From your journal…"). On Review, hide sections that are empty and keep a single summary line. Shots: `w1180_os_people.png`, `w1180_os_journal.png`, `w1180_os_review.png`, `w1180_os_drafts.png`.
8. **regroup — Settings (`w1180_os_settings.png`, `w390_os_settings.png`).** "Smart suggestions" and "AI help" are two rows with the same icon. AI help reads "Working" at 390 but "On" at 1180, so the state contradicts itself. The Settings nav icon is ⓘ, the same glyph as the project-info icon on Today. "New area" floats as a button in the section header, and "Unpin" is a bare text button while other rows have chevrons. *Change:* merge into one row, "Suggestions · On", with the footnote "Uses AI for names it can't match". Use a gear icon. Make "Add area…" the last row inside the Areas group, the iOS way. Pinned dates rows open a detail view (chevron), and Unpin lives there.
9. **demote — Journal (`w390_os_journal.png` vs `w1180_os_journal.png`).** The phone shows "New entry" + "Write today" side by side, while desktop shows one "Write" button. Search is a field plus a separate "Search" button (a web-form pattern). *Change:* one "Write" button at every width. Search filters as you type, has no button, and stays hidden until there's at least 1 entry.
10. **regroup — Notes + Reading list (`w1180_os_notes.png`).** The Reading list card is stuck under Notes with no gap between the cards and has its own add field, so the page has two adds next to "New note". *Change:* move the Reading list out (to Write › Reading or the planned Learn space) or make it a pinned note. The Notes page keeps one add.
11. **demote — Site list (`w1180_os_site.png`, `w390_os_site.png`).** Each of the 50 rows shows title, path, type pill, Hidden pill, date and a link icon, under type chips, a search field, a Search button and an "All posts 50 items · 6 hidden" header. "All 50" in the chips and "50 items" in the header repeat the same count. *Change:* row = title + date, with the word "Hidden" as footnote meta when it applies. Move path and View live to the editor. Type is filtered only through the chips. Remove the header count and the Search button.
12. **regroup — Site editor (`w1180_os_site_edit_detail.png`).** The editor is a narrow monospace text box in its own card, beside a separate meta card, with an empty right third at 1180. It doesn't match the Notes and Journal editors. "Delete post" sits mid-form. *Change:* use the same full-width writing surface and type as Notes/Journal (17/26). Put Date, Summary, Tags and Visible in a "Details" inspector or sheet, and move Delete into the ••• menu, last and in red.
13. **demote — Task rows on phones (`w390_os_tasks.png`, `w390_os_areas_detail.png`).** One task takes four lines: title, "0/1" checklist count, pill + date, then a lone "×". The header also stacks "1 open" + "Open" section label + "Show done" pill. *Change:* one footnote line ("0/1 · Medical School · Today"). Delete becomes swipe/long-press only on touch. Drop the "1 open" subtitle and the "Open" header, and move "Show 1 done" to the list footer.
14. **remove — Capture sheet starts with navigation (`w1512_capture_open.png`).** It opens on "Write in the journal / Tasks board / Drafts / People · Go", which just repeats the sidebar, and its footnote teaches prefix syntax ("note: · person: · draft:"). *Change:* open with real suggestions (today's tasks, recent notes and drafts, people mentioned this week). Replace the prefix syntax with a small Task / Note / Person / Draft segmented control above the field.
